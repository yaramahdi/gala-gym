# Jalaa Gym --- Project Guidelines

> Version: 1.0\
> Project Type: Premium Gym Website\
> Framework: React + Vite + Tailwind CSS + Framer Motion

------------------------------------------------------------------------

# Project Vision

Jalaa Gym is not just another gym website.

The goal is to create a premium digital experience that makes visitors
feel they are already inside the gym.

The design should reflect luxury, strength, simplicity and
professionalism.

------------------------------------------------------------------------

# Brand Personality

-   Premium
-   Modern
-   Powerful
-   Minimal
-   Elegant
-   Professional
-   High-end

------------------------------------------------------------------------

# Target Audience

-   Beginners
-   Men
-   Women
-   Weight-loss seekers
-   Muscle-building enthusiasts
-   Cardio lovers

------------------------------------------------------------------------

# Technology Stack

-   React
-   Vite
-   Tailwind CSS
-   Framer Motion
-   Lucide React

Do NOT use:

-   Bootstrap
-   jQuery
-   Heavy UI libraries

------------------------------------------------------------------------

# Design Philosophy

Inspired by:

-   Nike
-   Apple
-   Gymshark
-   Technogym

Use whitespace, smooth animations and clean layouts.

------------------------------------------------------------------------

# Colors

Primary: #FFC107

Primary Hover: #FFD54F

Background: #0A0A0A

Dark Surface: #141414

Secondary Surface: #1E1E1E

White: #FFFFFF

Gray: #F7F7F7

Borders: rgba(255,255,255,.08)

------------------------------------------------------------------------

# Typography

Headings:

-   Bebas Neue

Body:

-   Inter

------------------------------------------------------------------------

# Spacing

8 • 16 • 24 • 32 • 48 • 64 • 96 • 128 • 160

------------------------------------------------------------------------

# Border Radius

Buttons: 16px

Cards: 24px

Images: 28px

Inputs: 16px

------------------------------------------------------------------------

# Animations

Use Framer Motion.

Allowed:

-   Fade
-   Slide
-   Scale
-   Stagger

Duration:

0.5--0.8 seconds

Avoid bounce and rotation.

------------------------------------------------------------------------

# Component Rules

Reusable components only.

No duplicate code.

Tailwind only.

Responsive on all devices.
